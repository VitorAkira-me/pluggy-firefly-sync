# 0001. Firefly III é a fonte da verdade

**Status:** aceita (set/2026)

Toda conta, transação, categoria, orçamento e cofrinho vive no Firefly III. Nenhum outro
armazenamento guarda saldo oficial. Escrita só pela API oficial. Exceção controlada: o
saldo de conta corrente exibido no relatório vem da Pluggy, porque o Firefly só conhece o
que já foi importado (ver operacao.md, "Saldo menor que o real").
